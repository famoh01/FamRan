# 🌙 Fam Ai · Campus Wars

เกมอาร์เคดแอ็กชันแนว “โรงเรียนป่วน” ทำมือใหม่ทั้งหมดด้วย **HTML5 Canvas**
เล่นได้บนมือถือ (**แนวตั้ง / แตะอย่างเดียว**) และมี **ไฟล์ APK** ให้ติดตั้งจริง

> ⚠️ เกมนี้ **ไม่ได้** คอมไพล์จากโปรเจกต์ Unity `RanMobileCampusWars.rar` โดยตรง
> (รายละเอียดข้อจำกัดอยู่ในหัวข้อท้ายไฟล์) — แต่เป็นเกมที่ **ทำต่อจากคอนเซปต์เดียวกัน**
> คือ KlassX / Campus Wars (นักเรียนสู้กับแก๊งในโรงเรียน)

## 2) วิธีเล่น (มือถือ)

- **จอยด้านซ้าย** — ใช้ร่างกายของจอยเป็นพื้นที่แตะ ลากนิ้วไปทางไหน ตัวละครเดินทางนั้น
- **ปุ่มขวา ⚔️ ใหญ่** — กดค้าง = โจมตีต่อเนื่อง
- **ปุ่มสกิล 2 ปุ่ม** — ปลดล็อกที่ Lv.2 และ Lv.4 (มีวงแหวนนับคูลดาวน์)
- **🧪** — กินยาฟื้นเลือด (ซื้อเพิ่มได้ที่ร้านค้า)
- **⏸** — พักเกม / เข้าร้านค้า / ดูเควสต์ / ตั้งค่า

> เล่นจบได้: เก็บเลเวล → อัปอาวุธ/เกราะ → ลุย 3 ด่าน → ปราบบอสทั้ง 3 ตัว

### ตัวละคร
| สาย | จุดเด่น | สกิล |
| --- | --- | --- |
| 🗡️ นักรบ | เลือดหนา 150 HP ฟันแรง ระยะสั้น | ฟันคมหิน / โล่พสุธา |
| 🔮 จอมเวท | ยิงไกล มี AoE เลือดบาง 105 HP | ลูกไฟ / วงเวทน้ำแข็ง |
| 🏹 นักธนู | ยิงไวสุด ระยะไกลสุด วิ่งเร็ว | ฝนลูกศร / ก้าวลม |

### ด่าน
1. **ลานหน้าโรงเรียน** — บอส: หัวหน้าแก๊งปี 3 (620 HP)
2. **อาคารเรียน A** — บอส: ครูใหญ่เงา (1,500 HP)
3. **ดาดฟ้าเงามืด** — บอส: ราชาโรงเรียน (3,200 HP)

มี 6 เควสต์ (กำจัด / เก็บกระเป๋า / ปราบบอส) ให้รางวัล XP + เงิน 🌙
เซฟอัตโนมัติลงเครื่อง (localStorage) — ปิดแอปแล้วกลับมาเล่นต่อได้

## 3) ติดตั้ง APK

1. คัดลอก `FamAi_CampusWars.apk` ลงมือถือ (สาย USB / Google Drive / LINE อะไรก็ได้)
2. เปิดไฟล์ → Android จะถาม “อนุญาตติดตั้งจากแหล่งที่มาที่ไม่รู้จัก” → อนุญาต
3. กดติดตั้ง → เปิดแอป **Fam Ai Campus Wars**
4. ถ้าต้องการถอน: กดค้างที่ไอคอน → ถอนการติดตั้ง

> APK เซ็นด้วยคีย์ทดสอบ (self-signed) เหมาะกับการใช้งานเอง/แจกเพื่อน
> ถ้าจะขึ้น Play Store ต้องสร้างคีย์ของตัวเองแล้วเซ็นใหม่ + ทำตามนโยบายของ Google

## 4) เล่นบนเว็บ / โฮสต์เอง

```bash
# ต้องเสิร์ฟผ่าน http (ไม่ใช่ file://) เพราะใช้ ES module
cd CampusWars
python3 -m http.server 8080
# เปิด http://localhost:8080
```
- ฝังขึ้นเว็บได้เลย (static host, GitHub Pages, Netlify ฯลฯ)
- มี `manifest.webmanifest` + `sw.js` → ติดตั้งเป็น PWA ได้ (Add to Home Screen)

## 5) โครงสร้างโค้ด

```
CampusWars/
├─ index.html          # หน้าจอทั้งหมด + HUD + CSS (ไม่มี dependency ภายนอก)
├─ manifest.webmanifest, sw.js
├─ src/
│  ├─ data.js          # คลาส, ศัตรู, ด่าน, เควสต์, ร้านค้า (แก้ balancing ที่นี่)
│  ├─ engine.js        # game loop, ฟิสิกส์, AI, สกิล, เก็บเซฟ, เรนเดอร์ canvas
│  ├─ ui.js            # เมนู/HUD/ร้านค้า/เควสต์/หน้าจอเคลียร์ด่าน
│  └─ audio.js         # เสียงเอฟเฟกต์ WebAudio (สังเคราะห์เอง ไม่มีไฟล์เสียง)
└─ build/              # ไอคอน
```

### อยากปรับเกม?
- ยาก/ง่าย → แก้ `ENEMIES[x].hp/atk` หรือ `CLASSES[x].hp/atk` ใน `src/data.js`
- เพิ่มด่าน → เพิ่ม object ใน `ZONES` + ศัตรูใน `ENEMIES` + เควสต์ใน `QUESTS`
- เปลี่ยนชื่อแบรนด์ → `BRAND` / `TITLE` ใน `src/data.js` และ `<title>` ใน `index.html`

## 6) ข้อจำกัดที่ต้องบอกตรง ๆ

1. **ไม่ได้ build จากโปรเจกต์ Unity ที่ส่งมา** — `RanMobileCampusWars.rar` เป็นโปรเจกต์
   Unity 6000.3.25f1 (URP, 89 ฉาก, 4,201 สคริปต์ C#, AssetRipper decompile ของ KlassX)
   ซึ่ง **การ build ต้องใช้ Unity Editor + License + Android NDK/IL2CPP** และโปรเจกต์ใหญ่ ~8.8 GB
   เครื่องที่ทำงานนี้ไม่มี Unity จึง **คอมไพล์เป็น APK จากโปรเจกต์นั้นไม่ได้**
2. **APK ที่ให้ไป = เกมที่สร้างใหม่ (HTML5) ใส่ใน WebView** — ไม่ใช่ตัวไคลเอนต์ KlassX เดิม
   ฉาก/โมเดล/โมชันจาก Unity ต้นฉบับไม่ได้ถูกนำมาใช้
3. **ไม่มีไฟล์ `.apk` หรือ keystore อยู่ในไฟล์ RAR ที่ส่งมา** (เป็นซอร์สโค้ดอย่างเดียว)
4. ตัวเกม **ออฟไลน์ 100%** ไม่มีเซิร์ฟเวอร์ ไม่มีระบบล็อกอิน/มินิเกมหลายคน
5. ลิขสิทธิ์: โปรเจกต์ต้นทาง (KlassX) ไม่ได้แนบไลเซนต์มา — ถ้าจะเอาไปใช้เชิงพาณิชย์
   ต้องตรวจสิทธิ์กับเจ้าของเดิมก่อน ส่วนโค้ดเกมนี้เขียนขึ้นใหม่ทั้งหมดในงานนี้

## 7) อยากได้เวอร์ชัน Unity จริงไหม?

ถ้าคุณมีเครื่อง Windows + ติดตั้ง **Unity 6000.3.25f1 (หรือใกล้เคียง) + Android Build Support**
ผมช่วยได้โดย:
1. แก้/รีแฟคเตอร์สคริปต์ใน `Assets/Scripts` ให้บิลด์ผ่าน
2. ปรับ `Assets/Editor/BuildKlassx.cs` (มีอยู่แล้วในโปรเจกต์) ให้ชี้ path ที่ถูก
3. แนะนำการตั้งค่า Keystore / Player Settings / IL2CPP ARM64

บอกได้เลยว่าจะเอาแนวไหน: **ต่อยอดเกม Unity เดิม** หรือ **ขยายเกม HTML5 นี้**
